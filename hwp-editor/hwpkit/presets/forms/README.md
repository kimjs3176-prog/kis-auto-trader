# 기본 양식 폴더

여기에 `.hwp` / `.hwpx` 양식 파일을 넣으면 프로그램의 `양식·메일머지` 분류에
자동으로 나타납니다. (원본처럼 코드에 기관 서식을 넣지 않습니다)

- 개인 양식은 `%USERPROFILE%\.hwpkit\forms` 에 넣는 것을 권합니다.
- 공용 양식 폴더는 환경변수 `HWPKIT_FORMS` 로 지정합니다. (여러 개는 `;` 로 구분)

양식에서 값이 바뀌는 자리에는
1. 한/글 누름틀(필드)을 심거나,
2. `{{제목}}`, `{{수신}}`, `{{성명}}` 처럼 적어 두세요.

두 방식 모두 `양식 채우기`·`메일머지` 가 알아서 채웁니다.
