# 한글 문서 도우미 (HwpKit) — 범정부오피스 개선판

첨부하신 `범정부오피스20250819.exe` 를 분석해, **주요 기능만 남기고 구조를 다시 세운
개선판**입니다. 원본과 같은 방식(윈도우 + 한/글 COM 자동화)으로 동작하므로 실제
한/글 문서를 그대로 편집합니다.

## 원본 분석 결과

PyInstaller 로 묶인 Python 3.11 + tkinter + pywin32 프로그램이었습니다.

| 항목 | 원본 |
|---|---|
| 핵심 클래스 | `기본한컴` 하나에 메서드 **871개** (연결·글자·표·기관별 서식 혼재) |
| 화면 | 창 **100개 이상**, 탭 19개, 버튼 이미지 PNG **17MB** |
| 기관 한정 기능 | 광주 63 · 산인공 47 · 남해 34 · 합천 33 · 경남 32 · 서울 20 … |
| 중복 | 소제목 10곳, 대제목 9곳, 보도자료 5곳, 목차 5곳, 표 생성 함수 40여 개 |
| 테스트 | 없음 (텍스트 로직이 COM 호출과 붙어 있어 검증 불가) |

## 이번 개선판에서 한 일

1. **기관 한정 기능 전부 제거** — 광주·경남·남해·서울·인천·용인·산인공·행안부 등
   기관 전용 함수와 탭을 모두 없앴습니다. 대신 회사·기관 양식은
   `양식 폴더`에 파일만 넣으면 쓰도록 바꿨습니다(아래 *우리 회사 양식 쓰기*).
2. **중복 통합** — 기관마다 복제돼 있던 구성요소를 한 파이프라인으로 합쳤습니다.

   ```
   마크업 텍스트  →  요소 트리(text/markup.py)  →  렌더러(features/report.py)  →  한/글 문서
   ```

   | 원본에서 흩어져 있던 것 | 통합 결과 |
   |---|---|
   | 대제목·소제목·중제목·제목 함수 30여 개 | 마크업 `제목:` `소제목:` `중제목:` + `presets/styles.json` |
   | 네모·원·바·점선박스·꺽쇠박스·서론박스·요지박스 20여 개 | 마크업 `네모:` `원:` `바:` `참고:` `강조:` |
   | 기본표·심플표·3단표·5단표·퍼센트표 등 40여 개 | `표 만들기(열·행·스타일)` + `presets/table_styles.json` |
   | 정책·상황·검토·회의·행사·동향 보고 틀 16종(기관별 중복) | `presets/report_templates.json` 표준 유형 12종 |
   | 폰트×크기 조합 버튼 100여 개 | `글자모양()` / `문단모양()` + 스타일 프리셋 |
   | 문자 탭 버튼 49개 | `presets/symbols.json` |
3. **화면 재편** — 창 100개 대신 **사이드 패널 한 장 + 타일 격자**입니다.
   - 패널을 화면 **상·하·좌·우** 중 한 곳에 붙여 놓고 한/글 문서를 옆에 두고 씁니다.
     고른 자리는 다음에 켤 때도 그대로입니다.
   - **항상 위**로 띄워 두면 한/글을 눌러도 패널이 뒤로 숨지 않고, **투명도**를
     낮추면 패널 뒤의 문서가 비쳐 보입니다(40~100%). 둘 다 도구줄에서 바로 조절합니다.
   - 주요 기능은 **둥근 흰 카드 타일**로 늘어놓습니다. 분류 8개(블록 편집 / 표 / 서식 /
     문서 / 보고서 만들기 / 양식·메일머지 / 일괄 처리 / 도구)마다 아이콘 배지 색이 달라
     목록을 읽지 않고 눈으로 찾습니다. 칸 수는 패널 폭에 맞춰 저절로 바뀌고,
     타일 크기는 `칸` 단추로 세 단계(작게·보통·크게)로 바꿉니다.
   - 배색·모양은 **토스(Toss) 앱을 참고**했습니다 — 옅은 회색 바탕에 흰 카드,
     테두리 대신 여백과 둥근 모서리, 파랑 하나만 주 색으로. 둥근 카드·알약 단추·
     미끄럼자는 tkinter 기본 위젯으로 되지 않아 캔버스에 직접 그렸습니다.
   - 위쪽 검색칸에 낱말을 넣으면 타일이 즉시 걸러집니다(명령 팔레트).
   - 타일을 누르면 같은 자리에 실행판이 열립니다. 입력이 필요한 기능은 정의만 보고
     입력칸을 **자동 생성**합니다.
4. **기능 강화**(원본 문제를 고친 부분)
   - 셀 블록 인식이 **끄는 방향과 무관**해졌습니다. (원본은 ↘ 방향만 정상 동작)
   - 셀 주소를 A~Z 한 글자로만 계산하던 문제를 고쳐 **AA열 이후도** 처리합니다.
   - 표 대량계산이 병합된 셀에서 엉뚱한 칸을 쓰던 문제를 고쳤습니다.
   - 표 너비를 함수마다 다른 상수(205·196·161…)로 박아 두던 것을 **실제 본문 너비 계산**으로 바꿨습니다.
   - `한글금액`의 만/억 단위 오류(예: 200000 → 단위 누락)를 고쳤습니다.
   - 블록 계산기를 안전한 파서로 다시 써서 잘못된 수식에 죽지 않습니다(`eval` 미사용).
   - 작업 도중 실패하면 **자동으로 되돌려** 반쯤 그려진 표가 남지 않습니다.
   - 한/글 **보안 모듈을 등록**해 파일 접근 확인 창이 뜨지 않습니다.
   - 순화 사전을 `presets/refine.json` 으로 분리해 부서 용어를 계속 추가할 수 있습니다.
5. **새로 넣은 기능**
   - **개인정보 검사·가리기**: 주민번호·연락처·계좌·이메일·차량·여권번호를 찾아
     목록으로 보여주고, `900101-1******` 처럼 가립니다. (문서 전체 / 선택 영역)
   - **공문서 규정 검사기**: 날짜·시간·금액 표기, 항목기호 단계(□→○→-),
     붙임·끝 표시, 용지·여백을 점검합니다. 정답이 정해지는 표기는 자동 고치기 지원
   - **자동 목차**: 문서에 있는 제목(□ ○ 1. 가.)을 읽어 목차 표를 만들어 넣습니다
   - **작업 묶음(매크로)**: 여러 기능을 정해진 순서로 한 번에 실행
     (기본 제공: 받은 문서 정리 / 배포 준비 / 보고서 마무리 / 공문 표기 정리)
   - **사진 대장**: 폴더의 사진을 격자 표에 넣고 캡션(번호·이름·날짜)을 채웁니다
   - **표 계산 확장**: 열별 합계·소계 행 추가, 증감·증감률 열 추가,
     단위 환산(원↔천원↔백만원, 머리글 표기까지 함께 고침)
   - **표 ↔ 엑셀**: 표를 CSV/XLSX 로 내보내고, CSV/XLSX 를 표로 가져옵니다
     (엑셀이 깔려 있지 않아도 됩니다)
   - **폴더 일괄 처리**: 여러 문서의 찾아바꾸기·서식 정리·PDF 변환 (미리보기 지원)
   - **메일머지 개선**: CSV/XLSX 직접 읽기, 항목 개수 제한 없음,
     파일 이름 서식(`{성명}_{부서}`), HWP·PDF 동시 저장
   - **CLI**: `python -m hwpkit 실행 …` 으로 예약·자동 실행 가능 (영문 별칭 `run`·`check` 등 지원)
   - **연결 진단**: 연결이 안 될 때 자동화 등록·실행 중인 한/글·연결 시도를 차례로 점검
   - **테스트 300개** — 윈도우·한/글 없이도 로직이 검증됩니다.
   - **윈도우 exe 빌드 세트**: `build_win.bat` 한 번으로 exe 생성, `sign_win.bat` 으로 코드 서명

## 설치와 실행

```bash
pip install -r requirements.txt      # pywin32 (윈도우), openpyxl(xlsx 읽을 때만)
python -m hwpkit                     # 화면 띄우기
python -m hwpkit 점검                 # 한/글 연결 확인
```

### 원본처럼 exe 파일로 만들기

윈도우에서 `build_win.bat` 을 두 번 누르면 끝입니다. (가상환경 준비 → 의존성 설치 →
시험 300개 실행 → 빌드 순서로 진행하고, 시험이 실패하면 빌드를 멈춥니다)

```
dist\한글문서도우미.exe        ← 원본처럼 한 파일 형태
```

exe 에는 아이콘과 제조사·버전 정보가 들어가고, UPX 압축을 쓰지 않으며 관리자 권한을
요구하지 않습니다. 모두 **백신 오탐과 보안 경고를 줄이기 위한 설정**입니다.

내려받기·실행 때 뜨는 경고를 없애는 방법(코드 서명, 인증서가 없을 때의 사내 배포
방법, 백신 오탐 신고)은 **[배포안내.md](배포안내.md)** 에 정리했습니다. 서명은
`sign_win.bat` 으로 합니다.

> 원본과 마찬가지로 실제 문서 편집은 **윈도우 + 한/글(한컴오피스)** 환경에서만 됩니다.
> 리눅스·맥에서는 기능 목록·도움말·테스트만 확인할 수 있습니다.
윈도우 PC 가 없다면 리눅스에서 Wine 으로도 만들 수 있습니다(결과물은 진짜 윈도우 실행 파일).

```bash
sudo apt-get install -y --no-install-recommends wine64
bash build_wine.sh            # dist_wine\한글문서도우미.exe
```

## 쓰는 방법

### 화면
1. 오른쪽 위 `좌` `우` `상` `하` 단추로 패널을 붙일 자리를 고릅니다. 한/글 창을 가리지
   않는 쪽에 붙여 두면 됩니다. `항상 위`를 켜면 한/글을 눌러도 패널이 숨지 않고,
   `투명도`를 왼쪽으로 밀면 패널이 옅어져 뒤 문서가 비쳐 보입니다.
2. 기능 타일을 눈으로 찾거나, 검색칸에 `콤마`, `표`, `보고서`, `PDF` 처럼 낱말을 넣어
   걸러 냅니다. 아래 칩(`전체` `블록 편집` `표` …)으로 분류만 볼 수도 있습니다.
   타일이 작으면 `칸` 단추로 크기를 키웁니다. 타일에 마우스를 올리면 아래 상태줄에
   전체 이름과 설명이 나옵니다.
3. 타일을 누르면 실행판이 열리고 입력칸이 생깁니다. 타일 아래에 `선택 필요`,
   `표 필요` 라고 적힌 기능은 한/글에서 먼저 부분을 선택하거나 표 안에 커서를 둡니다.
   연결이 안 될 때는 `진단` 으로 검색해 **한/글 연결 진단** 을 실행하세요.
4. `실행` 을 누르면 결과가 결과칸에 나옵니다. `← 목록` 으로 타일 격자에 돌아갑니다.

### 보고서 만들기 (원본 '마크다운' 기능의 확장)
```
제목: 2026년 스마트농업 확산 추진계획
소제목: 추진 배경
원: 스마트팜 보급률 12% → 21%로 증가
바: 노지 분야는 아직 초기 단계
표: 구분 | 2025년 | 2026년
표: 예산(백만원) | 1,200 | 1,850
강조: 상반기 공모 후 하반기 집중 지원
참고: 세부 산출근거는 붙임 1 참조
```
`보고서 유형으로 시작` → 유형을 고르면 위와 같은 골격이 채워지고, 내용을 고쳐
`실행` 하면 서식이 적용된 한/글 문서가 만들어집니다.

### 자주 쓰는 흐름

| 하고 싶은 일 | 기능 |
|---|---|
| 공개 전 개인정보 확인 | `문서 → 개인정보 검사` → `개인정보 가리기` |
| 공문 규정 점검 | `문서 → 공문서 규정 검사` → `규정 표기 자동 고치기` |
| 보고서 목차 넣기 | `문서 → 문서 제목 목록 보기` 로 확인 후 `목차 자동 만들기` |
| 예산표 마무리 | 표 선택 → `합계·소계 행 추가` → `증감 열 추가` → `단위 환산` |
| 표를 엑셀로 | 표 선택 → `표를 엑셀·CSV 로 내보내기` |
| 엑셀 자료를 표로 | `엑셀·CSV 를 표로 가져오기` |
| 현장 사진 정리 | `표 → 사진 대장 만들기` (폴더 지정) |
| 매번 같은 마무리 | `도구 → 작업 묶음 실행` |

### 명령줄
```bash
python -m hwpkit 목록 --분류 표
python -m hwpkit 도움 표.대량계산
python -m hwpkit 실행 도구.날짜변환 날짜=2025-3-9 서식=공문 넣기=0
python -m hwpkit 실행 일괄.PDF 폴더=C:\보고서 하위폴더=1
python -m hwpkit 실행 메일머지.실행 양식=출장신청서 자료=명단.csv 저장폴더=C:\결과 파일이름={성명}
```

## 우리 회사 양식 쓰기

기관별 하드코딩을 없앤 자리를 이 구조가 대신합니다.

1. 양식 폴더에 `.hwp` / `.hwpx` 파일을 넣습니다.
   - 개인 양식: `%USERPROFILE%\.hwpkit\forms`
   - 공용 양식: 환경변수 `HWPKIT_FORMS` 에 폴더 지정 (여러 개는 `;` 로 구분)
2. 양식에서 값이 바뀌는 자리에 **누름틀(필드)** 을 심거나, 그냥 `{{제목}}`,
   `{{수신}}` 처럼 적어 둡니다.
3. `양식 → 등록된 양식 보기` 에 자동으로 나타납니다. `양식 열기` 로 채울 항목을 확인하고,
   `메일머지` 로 명단(CSV/XLSX)만큼 한 번에 만들 수 있습니다.

겉모습(폰트·표 색·여백)을 회사 기준에 맞추려면 코드 대신 프리셋만 고치면 됩니다.

| 파일 | 고치는 내용 |
|---|---|
| `hwpkit/presets/styles.json` | 제목·소제목·본문 폰트/크기/여백 |
| `hwpkit/presets/table_styles.json` | 표 테두리·머리글 색 |
| `hwpkit/presets/report_templates.json` | 보고서 유형 골격 |
| `hwpkit/presets/refine.json` | 순화 사전(부서 용어) |
| `hwpkit/presets/symbols.json` | 기호 목록 |
| `hwpkit/presets/macros.json` | 작업 묶음(매크로) 순서 |

## 구조

```
hwpkit/
  core/        한/글 COM 연결·문서 조작 (얇은 계층)
    connection.py  실행 중인 한/글 붙기, 보안 모듈 등록, 재연결
    document.py    액션·파라미터셋 처리, 선택 영역, 셀 범위, 저장, 작업 묶음(되돌리기)
```
